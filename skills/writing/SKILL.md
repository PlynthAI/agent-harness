# Writing

For "unslop this", "make this read less like AI", "tighten the prose" or another
finishing edit of supplied text, go directly to [unslop](unslop/METHOD.md).
Return the revised text; a new draft is not required. For a broader revision,
read the genre's route and revise the existing draft through the flow below.
For academic prose, preserve hedges, claim strength, terms of art, citations
and venue conventions through every editing and finishing pass.

1. **Name the deliverable.** Settle the genre, audience, the action or
   understanding the reader needs, the channel and the owning document from
   the request and project guidance.
2. **Find the style authority.** A named venue, journal, client or brand
   guide wins, then the project's voice, audience, approved-claims and copy
   guides via its `AGENTS.md`, `PROJECT.md` or subject map. The route
   reference's defaults fill only the gaps; if a genre expects a guide and
   none exists, use the default and say so in the hand-back.
3. **Read the one route reference** that matches; two genres read both.
4. **Draft or revise within scope** and the stance below. Ground material claims in
   inspected sources; use [research](../research/SKILL.md) when they need
   current external evidence.
5. **Finish with [unslop](unslop/METHOD.md)** once the draft is right. Not
   for chat replies.

## Drafting stance

Orwell's six rules ("Politics and the English Language"), each with the
[unslop catalogue](unslop/references/catalogue.md) rule that checks it.

1. Swap a figure of speech often seen in print for the literal claim (34).
2. Use the short word when it does the job (31).
3. Cut every word the sentence can lose (23).
4. Use the active voice and name the actor (29).
5. Use the everyday word over jargon (26).
6. Break any of these rules sooner than write something clumsy or unclear, so
   a pass never twists a sentence to obey one (the catalogue's opening note).
