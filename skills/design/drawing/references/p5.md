# p5.js

Use p5.js for expressive generative studies, sketches, animation, interaction or
shaders where a creative-coding runtime helps. The whole p5 constructor is
available; the patterns below are working guidance, not a method allowlist.
Inspect the installed version's reference (https://p5js.org/reference/) when an
advanced method is needed, and record that version: rendering can change between
releases.

## Mode and renderer

Prefer instance mode for portable work, multiple canvases and clean embedding:

```js
const sketch = (p) => {
  p.setup = () => {
    p.createCanvas(width, height);
    p.randomSeed(seed);
    p.noiseSeed(seed);
    p.noLoop();
  };
  p.draw = () => drawArtwork(p, spec);
};
new p5(sketch, container);
```

Choose the default 2D renderer for linework, shape, image, type and pixel
composition. Choose WebGL only when depth, custom geometry, textures, shaders or
GPU instancing materially improve the work, and record the choice, because
coordinates and results differ.

## Author with intent

- Seed both the random and the noise families whenever a result must reproduce.
- Build large structure before high-frequency detail.
- Give offscreen graphics layers semantic roles - wash, geometry, grain, type,
  masks - rather than using them as scratch space.
- For static work, render once with no loop and redraw on parameter change; keep
  animation only when motion is the output.
- Expose composition, density, palette, turbulence, mark, camera and layer
  controls in the spec instead of burying literals.
- Freeze dimensions, pixel density, fonts, colour mode, assets and blend modes.
  A lower preview density is fine; the export must not be simplified.
- Never import from a mutable CDN in a portable artifact: use the pinned package
  or a bundled, integrity-checked build.
- Combine a brush runtime, native Canvas, SVG or Three.js when that produces a
  better image.
